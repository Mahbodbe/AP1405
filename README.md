## 🛠️ راهنمای اجرا

### بخش $C++23$
با توجه به اینکه مباحث بر پایه استاندارد جدید **$C++23$** پیاده‌سازی می‌شوند، برای کامپایل کدها به کامپایلری نیاز دارید که از این استاندارد پشتیبانی کند (مانند GCC 13+ یا Clang 16+):

bash
g++ -std=c++23 main.cpp -o main
./main

### بخش Python
کدهای پایتون با نسخه ۳ به بالا سازگار هستند و ترجیحاً از آخرین نسخه‌های پایدار پایتون استفاده کنید:

bash
python main.py
